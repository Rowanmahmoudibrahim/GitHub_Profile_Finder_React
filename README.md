# GitHub Profile Finder

A responsive **GitHub Profile Finder** web application built with **React**, **Vite**, and **Tailwind CSS**, allowing users to search GitHub profiles by username or Arabic name and explore their latest repositories.

## ✨ Key Features
- **Profile & Repository Fetching:** Fetches GitHub user details and latest repositories using `useEffect`, `async/await`, and `AbortController` to cancel outdated requests cleanly.
- **Arabic & English Search Support:** Supports searching by GitHub username as well as Arabic names, with dynamic `placeholder` adaptation based on typed characters.
- **Bilingual UI (`EN` / `AR`) & `RTL` / `LTR`:** Instant language switching with automatic layout direction adjustment.
- **Dark & Light Mode:** Smooth theme toggle with clear typography and contrast across both modes.
- **Profile Insights & Repository Controls:** Copy profile link, view top languages in latest repositories, filter repositories by programming language, and sort by latest updated or stars.
- **Responsive Design:** Adapted for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **React** (Hooks: `useState`, `useEffect`)
- **Vite**
- **Tailwind CSS**
- **GitHub REST API**
